API server
{{probeText}}
Learn more
This dashboard is a static page — hosted anywhere, pointed at any workstation. The service binds loopback by default and carries no in-app auth; this page's origin is allowed to read it out of the box (service.cors.allowOrigins). A service on another machine still needs to reach this browser — an SSH tunnel (ssh -L 8787:127.0.0.1:8787 workstation) or a gateway that terminates auth. The URL is saved in this browser; the health check is GET /api/v1/health.

The demo serves a bundled fixture in the same record shapes the service uses, so the screens can be evaluated without a reachable workstation. Control verbs in demo mode mutate an in-memory copy and never leave the browser.
Refresh
How this browser keeps the screen current
Learn more
Each poll cycle is four list calls plus one graph/check per active loop, so a large board against a remote workstation is happier at 30s. Streaming costs one held-open connection instead, and refreshes only what each change touches. A stream that cannot be opened says so in the header's health dot and falls back to polling.
Service
{{restartReport}}
Learn more
Stops every running the-loop service on the workstation, then starts every enabled one — the same thing the-loop restart does. With the upgrade, the CLI is upgraded in between; a failed upgrade still restarts the current version.
CLI config
The daemon's own configuration, read from ~/.the-loop/cli-config.yaml. A save changes only the fields you changed and leaves the file's comments alone; the poller and receiver pick it up on their next cycle.
