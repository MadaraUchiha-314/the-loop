## Verification environment

- **Repositories:** this repository, plus throwaway clones of it under the session's
  scratch directory for T5.
- **Services / containers:** none for T1–T4, T8. T5 runs a local HTTP server
  (`fake_anthropic.py`, in the scratch directory, reproduced in `evidence/pipeline.md`)
  standing in for `api.anthropic.com` through `ANTHROPIC_BASE_URL`. T6/T7 are GitHub
  Actions.
- **Fixtures & data:** T2 builds bare repositories under `tmp_path`.
- **Credentials:** none in this container. T7 needs `ANTHROPIC_API_KEY` on the
  `graphify` environment — **by reference only**; the owner adds it.
- **Bring-up:** `uv sync`; `uv tool install --with anthropic graphifyy==0.9.64` for T5.
  **Tear-down:** the clones are deleted with the scratch directory.
- **If bring-up fails:** record it under Verification results, leave the dependent
  activities unticked, and escalate.
